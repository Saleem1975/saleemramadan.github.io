House Flip Rehab & Investment Analyzer

An Excel-based decision-support model for translating property condition, rehab scope, costs, bids, financing, schedule, and sale assumptions into investment KPIs and dashboards.

Excel Cost Analytics Financial Modeling KPI Dashboards Variance Analysis

Executive-overview representation of the workbook's worked-example decision-support structure.

What I Built

  • A multi-sheet Excel decision-support model linking property inputs, rehab scope, cost estimates, bids, financial assumptions, and performance tracking.
  • A structured rehab cost library with trade, unit, allowance, risk, permit, and material/labor/other cost components.
  • Formula-driven analysis for rehab budget, contingency, projected and actual profit, ROI, maximum allowable offer, budget variance, schedule variance, and profit per day.
  • Dashboard views for acquisition, rehab, risk, profitability, and project-performance decisions.

Analytics Value

The model demonstrates structured data organization, cost modeling, KPI design, scenario evaluation, variance analysis, and dashboard-based decision support in a practical real-estate investment context.

Worked Example

The included workbook uses example project values to demonstrate the analytical workflow. Property-specific use requires replacing the example inputs with actual inspection findings, contractor bids, financing assumptions, schedule information, and sale data.
